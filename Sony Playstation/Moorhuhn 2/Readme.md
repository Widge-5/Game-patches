## Moorhen 2 – English Translation v2.0 ##

An expanded English translation of the German PlayStation release, **Moorhuhn 2: Die Jagd geht weiter**.

Translation Patch Version 2.0 builds on **John Osborne’s original v1.1 English translation**, retaining his work while improving the wording, correcting errors and translating additional graphics.

Changes beyond the original patch include:

- “Moorhen” branding on the title, main menu and calibration screens.
- Translated publisher and developer introduction screens.
- Revised menus, minigame names, score messages and Memory Card text for clearer, more consistent English.
- Corrections to remaining German text, incorrect messages and broken numeric placeholders.

A matching English translation of the original German manual is also available, preserving its original design and layout.

The translation patch is compatible with the separate **Lightgun Accuracy patch**. Use both together if you wish.

Apply the **PPF** to a single BIN from either the unmodified German PAL release, **SLES-03278**, or one already patched with the Lightgun Accuracy patch. This full patch includes the original translation and all v2.0 improvements.



## Moorhen 2 – Lightgun Accuracy Patch v1.0 ##

Moorhuhn 2’s lightgun aiming has two problems: uneven scaling and input lag.

The original game applies different scaling to aiming coordinates on either side of the calibration point. As a result, the crosshair can line up correctly near the centre but drift away from the gun’s sights towards the edges. In-game calibration alone does not fully correct this.

The game also processes aiming coordinates in a way that adds noticeable delay. The crosshair—and therefore the shot position—trails behind the player’s physical aim.

The **Lightgun Accuracy** patch corrects the directional scaling and reduces that additional delay. It automatically selects the appropriate corrections for GunCon or Konami guns on each controller port, including mixed two-player setups.

These improvements benefit both original hardware and emulation. They improve alignment and responsiveness. The patch also removes teh player crosshairs during gameplay, but keeps it visible in menus and calibration screens.

Note, although not documented in the manual, the game does support the Konami Hyperblaster lightgun, as well as the Namco GCon45.

The Lightgun Accuracy patch is compatible with the separate **English Translation patch v2.0**. Use both together if you wish.

Apply the **PPF** to a single BIN from either the unmodified German PAL release, **SLES-03278**, or one already patched with the English translation patch v2.0.


**The cheat code option**
As an option, the Lightgun accuracy modifications do not need to be patched into the game's binary. They can be applied as cheat codes  in an emulator.  A Retroarch .cht file is also provided if this is preferable.  The Cheat file separates the Crosshair Invisibility from the rest of the Lightgun Accuracy, so either one or both can be applied as preferred.  The Cheat codes should be applied to the game before it starts running, or they may not take effect.
