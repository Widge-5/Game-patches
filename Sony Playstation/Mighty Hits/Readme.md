**An English translation patch for Mighty Hits, originally released for the Japanese PlayStation.**

This patch translates the original Japanese PlayStation release of Mighty Hits (SLPS-00583) into English. It translates menus, minigame instructions, lightgun calibration prompts and Japanese lettering in the graphics.

The English Sega Saturn release and Mighty Hits Special served as translation references. Where the editions differ, the translated instructions follow the original Japanese PlayStation game. Its stages, rules, scoring, difficulty, controls and timing have not been changed.

The completed patch has passed a full playthrough with no problems reported.


**Patching**

This patch was created using a CUE/BIN image, consisting of a single BIN file, ripped from a copy of the Japanese disc (SLPS-00583) using ImgBurn.

The release includes the translation patch and the fully translated, proofread English manual.

Apply the PPF3 patch to the unmodified BIN file. Do not apply it to the CUE file or an already-patched image.
