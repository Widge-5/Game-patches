**An English translation and lightgun enhancement patch for Guntu: Western Front June 1944, originally released for the Japanese PlayStation.**

**The patch translates the game’s Japanese text, including story screens, stage briefings, mission instructions, calibration instructions and opening and ending sequences.**

Additional features include:

- Clean, code-rendered prologue and ending text. This eliminates compression noise around the lettering and greatly reduces the patch size by avoiding replacement video files.

- Improved GunCon secondary-weapon aiming. Originally, secondary-weapon aim was locked to the position where A was first pressed, causing shots to land at that earlier position even after the player moved their aim. The patch retains hold-A selection but uses the player’s current aim when the trigger is pulled. Release A to return to primary ammunition.

- Reduced firing delay for primary and secondary ammunition.

- A fully translated and proofread English manual has also been created, updated to accompany the patched game.

- Original moving footage, music and audio are preserved. The final gold-background epilogue uses a stationary background with clean, rendered English text.


The completed patch has passed a full playthrough with no problems reported.


**Patching**

This patch was created using a CUE/BIN image, consisting of a single BIN file, ripped from my own copy of the Japanese game (SLPS-01106) using ImgBurn.

Use PPF-O-Matic to apply `Guntu (SLPS-01106) English translation patch v1.1.ppf` to the unmodified BIN file. Do not apply it to the CUE file or an already-patched image.

The release includes the translation patch and the fully translated, proofread English manual.
